# 🤖 Telegram Bot: telegram-bot_for_gym-nutrition-calories

At the moment, the application is launched from time to time for configuration purposes.

In future updates, it will be available at the following link: https://t.me/GymNutritionCalories_bot

---

## 🇷🇺 : Описание на русском языке

### Описание проекта

Несложный проект использующий две библиотеки:
- [Aiogram](https://docs.aiogram.dev/en/v3.28.2/api/index.html) для взаимодействия с клиентом Telegram;
- [SQLite](https://docs.python.org/3/library/sqlite3.html) для сохранения данных о стандартных и пользовательских продуктах питания.

### Возможности проекта

Стартовой точкой проекта являются следующие аспекты:

1. Создание удобных `InLine` и `Reaply` клавиатур для пользователя;
2. Настрока основных продуктов питания, на основе предпочтений создателей;
3. Добавление возможности создавать пользовательские списки продуктов питания;
4. Настроенный счётчик Калорий и значений БЖУ в промежутках: 1 день и 1 месяц;
5. _Возможно_, добавление возможности получить диаграму притания в указанные промежутки.

## 🇺🇸 : Description in English

### Project Description

A simple project using two libraries:
- [Aiogram](https://docs.aiogram.dev/en/v3.28.2/api/index.html) for interacting with the Telegram client;
- [SQLite](https://docs.python.org/3/library/sqlite3.html) for storing data about standard and custom food products.

### Project Features

The starting point of the project includes the following aspects:

1. Creating convenient `Inline` and `Reply` keyboards for the user;
2. Configuring basic food products based on the creators' preferences;
3. Adding the ability to create custom food product lists;
4. A configured calorie and macronutrient (BJU) counter for time intervals: 1 day and 1 month;
5. _Possibly_, adding the ability to obtain a nutrition chart for the specified intervals.
